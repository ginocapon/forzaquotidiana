Personal trainer Beta

Piattaforma coach · app atleta

Oltre al diario pubblico e alle schede PDF, qui vive l’app di allenamento personalizzato: piani, tracking live (serie, RIR, recupero), progressi e catalogo programmi.

Il sito che stai leggendo resta su GitHub Pages; l’app gira su server Node (cartella training-app/ nel repo). Collegamento configurato in data/training-app.json.

Programmi Area atleta Progressi

Cosa include

  • Coach (admin) — piani, microcicli, verifica programma vs eseguito, alert completamento, export report.
  • Atleta — login, scheda live, timer recupero, dashboard progressi, peso corporeo.
  • Vendita — catalogo Programmi, checkout Stripe, clone automatico del piano dopo pagamento.

Sviluppo locale

cd training-app
cp .env.example .env   # DATABASE_URL, PAYLOAD_SECRET
yarn install && yarn payload migrate
yarn dev               # http://localhost:3000

Documentazione tecnica: training-app/README.md · codice sorgente esteso da payload-training-app (MIT).
