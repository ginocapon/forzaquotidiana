# Venerdì — crono premortem + freschezza SEO

Esegui:

```bash
npm run venerdi:crono
```

Poi:

1. Leggi `guardian/reports/guardian-latest.md` — failure modes prioritizzati.
2. Applica **una** correzione oggettiva se il premortem segnala rischio ≥ contenuti/editoriale.
3. Foglio Google: iscritti, accessi scheda, newsletter se articolo nuovo.
4. Commit: `feed.xml`, `llms.txt`, `data/site-stats.json`, `data/biological-age.json` se cambiati.

Premortem manuale (piano newsletter / blocco allenamento): *«È già fallito tra 6 mesi — perché?»* — non *«va bene?»*.
